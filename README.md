## 怎么玩

选小男孩或小女孩出发，靠近人物即可交谈。用小地图找路。

电脑：WASD／方向键移动，Shift 小跑，E 互动，M 地图，B 背包。手机：摇杆和屏幕按钮。

直接打开 [index.html](index.html) 就能离线游玩。想从源码重新构建：

```sh
npm install
npm run build
npm test
```
