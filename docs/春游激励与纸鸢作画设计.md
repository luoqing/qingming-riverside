# 春游激励与纸鸢作画设计

这是一份待确认的玩法方案，尚未加入游戏。现有的逛摊、交谈、上桥、坐船和放纸鸢流程保持不变。新增的奖励只提醒孩子“我做成了什么”，不拿分数评判画得好不好，也不要求花钱才能完成故事。

## 完成一件事，留下一个印记

左上角的钱袋旁增加一枚小小的“春游印记”计数。任务完成时，数字轻轻跳一下，出现两秒的“+10”；随后画面恢复干净。印记不消费、不扣除，也没有排行榜。背包里可以查看已经完成的经历。

| 经历 | 印记 |
| --- | ---: |
| 帮阿芽解开纸鸢线 | 10 |
| 陪豆豆摇鼓 | 15 |
| 给花婆婆送花 | 15 |
| 在虹桥上观察风 | 10 |
| 坐一次汴河篷船 | 10 |
| 在船上留下一句见闻 | 10 |
| 为纸鸢画一笔或盖一枚图案 | 15 |
| 放飞纸鸢 | 15 |

总共 100 枚印记。每件事只加一次，重新进入游戏也不会重复加分。买东西仍只花铜钱，不给印记；不买拨浪鼓也能借鼓陪豆豆玩。这样孩子不必为了拿分而乱花钱。

## 让孩子亲手装饰纸鸢

放飞之前，阿芽把纸鸢拿近，问一句“今天想在上面留下什么？”纸鸢原有的小鼓、花朵、虹桥图案照常出现；孩子可以在空白处添画。作画直接发生在这只纸鸢上，不另开一个半屏任务页面。

电脑把鼠标指针显示成小毛笔，按住拖动即可画。手机用手指直接画，笔尖预览稍稍露在手指上方。只放三种颜色、一支粗细可调的笔，以及“撤销”“重画”“画好了”；每次操作都能看见纸鸢的变化。现有的故事图案继续自动出现，完成故事后还可选小鼓、花朵和虹桥图章，点一下盖在空白处。

画好的笔迹会贴到场景里的三维纸鸢上，放飞时也看得到。结尾沿用现有页面，能保存包含手绘笔迹的纸鸢图片。绘画和解锁图案会保存在当前浏览器；返回游戏后仍能继续画。孩子若不想画，可以直接放飞，故事照样结束，只是少了作画那 15 枚印记。

## 不打断原来的春游

引导仍是一小句一小句地出现。第一次获得印记时，阿芽说“这件事也画进今天的纸鸢吧”；之后只显示短暂的加分提示。地图、背包和结尾仍是仅有的大页面。印记和铜钱分开显示，避免孩子把奖励当成购物的钱。

实现时从已经保存的故事进度计算印记，避免重复领奖。手绘笔迹以相对坐标保存，不直接塞一整张大图片进存档；这样电脑和手机画出的内容都能贴合纸鸢，也方便撤销和继续绘画。

## 验收要看到的结果

- 完成任务只加一次印记；刷新页面后分数和画作还在。
- 鼠标和手指都能连续画线，画笔不会带着场景一起转动；撤销和重画有效。
- 场景里的纸鸢与最终保存的图片，能看见同一幅画。
- 不作画也能通关，不购买物品也不会卡住主线。
